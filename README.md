## 📖 About This Project

This repository is part of the **CS50x Persian** initiative, created to make high-quality computer science education accessible to **Persian-speaking learners**.

The project provides Persian-language resources for **Harvard University's CS50 Scratch**, helping students learn the fundamentals of programming through Scratch, a visual programming language designed to make programming accessible to beginners.

Throughout the course, students learn important programming concepts such as functions, events, values, conditions, loops, variables, and abstraction while creating interactive programs, animations, games, and stories.

Through **CS50x Persian**, Persian-speaking students can access professionally translated educational content, course materials, projects, and learning resources designed to make the CS50 Scratch curriculum easier to follow and understand.

Our goal is simple:

**To make world-class computer science education accessible to Persian speakers. ❤️**

---

## 🎓 About CS50 Scratch

**CS50's Introduction to Programming with Scratch** is Harvard University's introductory programming course that teaches the fundamentals of programming using **Scratch**, a visual programming language developed by the MIT Media Lab.

Instead of typing traditional programming syntax, students use graphical blocks that can be dragged and dropped together to create programs.

The course is designed for learners with little or no prior programming experience and introduces fundamental programming concepts that are also found in traditional text-based programming languages such as Python and Java.

Throughout the course, students build animations, games, interactive stories, and other creative projects while developing their computational thinking and programming skills.

The Persian edition makes these concepts accessible to students who prefer learning programming and computer science in Persian.

## 📚 What You'll Learn

Throughout CS50 Scratch, you will learn:

6. Loops
3. Events
4. Values
1. Sprites
7. Variables
2. Functions
5. Conditions
8. Abstraction

By the end of the course, you will have a strong foundation in programming fundamentals and computational thinking, and you will be able to use Scratch to design and build your own interactive projects.

Students who successfully complete the official CS50 Scratch course requirements may be eligible to receive a **free CS50 Certificate**.
